GETTING STARTED 如何游玩
01
下载客户端
点击首页的「下载客户端」按钮，安装 APK 到安卓设备。PC 端暂未编译，但可通过QQ:1018861459获取源码，直接在Godot Engine 4.7+上运行（Android端亦然）。
02
注册账号
打开客户端，用「注册」标签创建新账号。UID 至少 6 位， 密码至少 4 位。该账号在官网与游戏内通用。
03
进入战场
登录后选择模式：AI 对局、房间对战 或 大逃杀。 挑好你的英雄，点击开始。
  • 支持 PC（Windows / macOS / Linux）与 Android 双端
  • PC 键位：WASD 移动、空格跳跃、Shift 滑铲、右键开镜、左键开火
  • 移动端：左摇杆移动、右侧滑动视角、屏幕按钮射击 / 技能 / 拾取
  • 每位英雄拥有独立的战术技能（Q）与终极技能（X）
  • 留意缩圈提示与空投位置，圈外会持续掉血
OFFICIAL SERVER 连接官方服务器
wss://api.wowneon.dpdns.org 点击复制
在客户端登录界面的「服务器地址」一栏，粘贴上方地址即可连接官方服务器。
